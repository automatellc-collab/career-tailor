# Good Guys Plumbing — website

Single-page site for Good Guys Plumbing (Atlanta, GA, est. 2019). Call 770-313-8290.

- `index.html` is the whole site: no build step.
- English/Spanish toggle in the header. `?lang=es` opens straight in Spanish.
- "Open now" status is computed in Atlanta time from the hours Mon–Fri 9–6, Sat 9–5.
- The request form opens a prefilled text message to 770-313-8290.
