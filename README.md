# NeWave Power & Light — website concept

Single-page site for NeWave Power & Light (electrical services, Cobb / Fulton / Cherokee, GA).

- `index.html` + `assets/` — no build step.
- Facts come from the company van: name, slogan, phone, services, counties, licensed/insured, guarantee.
- `assets/van.jpg` is a photo of their van. The logo is an SVG recreation; swap in the real file when available.
- The EV readiness check is a rough first look (charger circuit sized at 125%); it says so on the page.
