# The Appliance Doctor — website concept

Redesigned front-end for myappliancedoctor.com (Marietta, GA; family-owned since 1980).

- `index.html` + `assets/` — no build step.
- All content is taken from the current site: services, brands, reviews (quoted as written), team photos, hours, service area.
- Shopping links go to the existing WebFronts catalog; "Schedule" opens their existing Broccoli booking widget (falls back to calling).
- The repair-or-replace checkup uses typical lifespan estimates and gives a first opinion only.
