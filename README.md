# JAD Plumbing — website concept

Single-page, English/Spanish site for JAD Plumbing LLC (770-369-7054). No build step.

- Facts come from the company van: services, Fully Insured, Free Estimates, Commercial & Residential, Spanish/English, phone and Gmail.
- Signature concept: "The Plumbing Plan", a blueprint drawing of a whole-house plumbing system with 8 tappable keynotes.
- Built and checked against Vercel's Web Interface Guidelines (`WEB_INTERFACE_GUIDELINES.md`, from vercel-labs/web-interface-guidelines).
- Automated accessibility scan (axe-core 4.10): 0 violations, desktop and phone.
- Language and estimate choices sync to the URL (`?lang=es&need=leak,heater`), so a link reopens the same state.
- The badge logo is an SVG recreation of the van's mark; swap in the original file when available.
