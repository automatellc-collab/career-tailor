# One Cut Tree Services — website concept

Enhanced single-page version of onecuttreeservicesga.com (Roswell, GA).

- `index.html` + `assets/` — no build step.
- Facts (18 years, 50-mile radius, hours, services, phone, email, socials) come from the current site.
- `assets/photos/` holds every unique photo the current site uses (24). `p1` and `p2` are the company's own job photos.
- The quote tool opens a prefilled text or email; nothing is sent automatically.
